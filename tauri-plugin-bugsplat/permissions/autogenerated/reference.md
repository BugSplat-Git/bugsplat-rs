## Default Permission

Lets webviews report JavaScript errors to BugSplat.

#### This default permission set includes the following:

- `allow-report-error`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`bugsplat:allow-report-error`

</td>
<td>

Enables the report_error command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`bugsplat:deny-report-error`

</td>
<td>

Denies the report_error command without any pre-configured scope.

</td>
</tr>
</table>
